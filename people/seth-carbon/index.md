Seth Carbon is the software manager and lead architect for the <a href="http://geneontology.org">Gene Ontology Consortium</a>, responsible for the structure of the GO's software and deployment environment and for the GO data pipeline, and advises the ARPA-H <a href="https://arpa-h.gov/explore-funding/programs/rapid">RAPID</a> SI/IV&amp;V effort at LBNL.

Current projects: the <a href="https://ai.geneontology.org">Gene Ontology AI Hub</a> (agentic curation), <a href="http://noctua.geneontology.org">Noctua</a> (GO-CAM annotation), the <a href="https://github.com/geneontology/pipeline-from-goa">GO Data Pipeline (GOEx)</a>, and CAT (an agentic research-group assistant). Other interests include data licensing and reuse through the <a href="http://reusabledata.org">(Re)usable Data Project</a>, language acquisition, and evolutionary biology.
